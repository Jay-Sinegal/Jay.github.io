# Provenance and Compliance Note (agents/)

Why this folder is legally clean to publish, operate, and sell.

## Source of the learning

Jaylen holds a personal LinkedIn (LinkedIn Learning) membership. The course used
to learn agentic-AI concepts is licensed for personal, non-transferable
viewing. Under the LinkedIn User Agreement, LinkedIn's learning videos and other
materials may not be copied or distributed.

## What this repo contains

- Only ORIGINAL materials: own SOPs (from `consulting-hub/`), own code, own
  prompts, own test data, and neutral naming.
- Nothing that was copied from, paraphrased-for-distribution from, or derived
  line-for-line from any course video, transcript, notebook, diagram, or
  exercise file.
- No course exercise files, data folders, SOP text, or notebook JSON are
  committed here or referenced as imports.

## Learned ideas vs copied expression

Copyright protects the author's specific expression, not the underlying ideas.
This project reuses GENERAL concepts that are standard in agentic-AI practice
(tool use, retrieval over a knowledge base, step planning, evaluation loops,
progressive autonomy). Those ideas are implemented originally over the practice
owner's own business documents and are not reproductions of course content.
Proprietary course framing labels used for study are NOT used in this
product's shipped naming.

## Standing rules (every person editing this repo)

1. Never copy course videos, transcripts, code cells, notebooks, diagrams, or
   exercise content into this repo - not even "for reference".
2. Production copy must be original writing over the owner's IP.
3. Do not distribute, re-upload, or embed any course material.
4. If a section of the code or docs is ever flagged as resembling third-party
   material, rewrite it plainly instead of attributing it.
5. Keep any personal study notes that quote the course OUTSIDE this repo.

This note exists to protect the owner and the clients of the practice.
