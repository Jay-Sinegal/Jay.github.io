## SECTION 1 — Social Media Scrub (LHSAA compliance check)

**Purpose:** Confirm the public footprint does not threaten amateur status or
violate the school's NIL policy. Education, not representation.

| # | Checkpoint | Answer (Yes/No/NA) | Notes |
|---|-----------|--------------------|-------|
| 1 | All public accounts are owned by the athlete or parent (no fake/third-party pages) | | |
| 2 | No account implies endorsement of alcohol, tobacco, or controlled substances | | |
| 3 | No deal, post, or mention references a specific school's recruiting pitch | | |
| 4 | No "for NIL" offers require enrollment at a particular school | | |
| 5 | No post offers, solicits, or implies payment for performance or bonuses | | |
| 6 | Parent/guardian has visibility and control of all private account credentials | | |
| 7 | LHSAA amateur status risk: LOW / MEDIUM / HIGH | | |

Risk rule of thumb:
- Any "recruiting motive" or "incentive for performance" item marked YES to a
  problem = stop and flag. Act 810 prohibits compensation contingent on
  enrollment or specific performance.
- Act 810 requires written parent/guardian consent before a minor signs a
  NIL agreement. If any agreement exists, verify the written consent exists.

Rule of thumb:
- If a platform holds the only copy of the athlete's film, that is a locked
  asset. The family outcome is always: independent proof of work the athlete
  controls, so no single platform owns the story.
